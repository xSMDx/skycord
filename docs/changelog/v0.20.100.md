# v0.20.100 — Windows only: buttons that match

The changelog for v0.20.100, in the voice of the landing page's `RELEASES` list (`landing/content.js`). Each line
is tagged as it is there: **imp** (improved) or **fix**. **This is a Windows-only update**, tagged
`desktop-v0.20.100`; see `docs/RELEASING.md`. The server and web client stay on **v0.20.99** (there is no
`v0.20.100` server tag), and there is no Android release.

Why 0.20.100 and not 0.20.99.1: electron-updater and npm need a three-part version, and a pre-release such as
0.20.99-1 would sort *below* 0.20.99, so installed apps would never be offered it.

Title: **Windows only: buttons that match**.

## Improved

- **imp** — **Skycord draws its own minimise, maximise and close buttons** in the Windows app, to match the rest of
  the title bar: they take your theme's colours, close turns red under the mouse, and maximise becomes restore while
  the window fills the screen.
  - One thing goes with Windows' own buttons: the Snap Layouts menu that appeared when you hovered over maximise.
    Win+Z still opens it, and dragging the window to an edge of the screen still snaps it.
  - Light mode (Settings › Performance) keeps the plain Windows frame and its buttons, as before.
  - **This update is for the Windows app only; servers stay on v0.20.99.**

## Fixed

- **fix** — **After updating to v0.20.99, the taskbar and Alt+Tab kept showing the old icon.** The app now sets its
  icon itself every time it starts, and the installer asks Windows to rebuild its icon cache, so a shortcut pinned
  to the taskbar or Start picks up the new one too.
- **fix** — **The title in the Windows app's bar** clipped the bottom of letters like g and q.
